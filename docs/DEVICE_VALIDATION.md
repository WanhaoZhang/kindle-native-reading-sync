# 设备验收清单（全部待真机完成）

本清单把“编译通过”“能启动”“能采集”和“真实到账”分开。缺少任何一类证据时，不应启用自动上传。软件自检不生成通过的耗电、翻页或入账证书。

## 1. 设备与运行环境

保持 PW2 / B0D4 / 5.12.2.1.1，不升级来迁就其他安装包。完成受信越狱与启动环境后，在设备 root 环境运行包内 `install/probe.sh`，核对 ABI、内核、型号前缀、root、Upstart、LIPC 和空间。安装候选包必须通过 SHA256 与 ARM ELF 检查。experimental-static-musl 包仍需本台实际运行，不等于 NiLuJe 工具链兼容认证。

运行 `ksync-worker --root /var/local/kindle-native-sync self-test` 检查本机与私有文件原子写入。只有显式加 `--online-self-test` 才探测远端 TLS；它不使用账号写入阅读时间，不代替休眠或性能测试。

## 2. 只采集阶段

首次启动只建立日志 EOF 基线；关闭并重新打开书籍，才开始新的窗口。验证长页停留不会触发空闲、关书原生日志能触发空闲。旧固件需要识别 ReaderBooklet 生命周期，不能假定存在 ReadingTimerController CloseBook。

依次检查正常翻页、关书后20秒空闲、飞行模式、联网恢复、合盖/唤醒、接USB/断开USB、重启、日志轮换、低空间。与 Mac 解析的每书每日 counted 秒及来源计数区间对照；未匹配或时钟证据不足不得补造。

测量整个服务树（采集器、事件适配器和固件 LIPC 监听子进程），不是只测一个 C PID。目标：常驻 RSS≤4MiB，30分钟平均CPU≤0.5%单核；worker峰值≤32MiB。与停用时同书、字体、亮度等条件比较至少200次翻页，P95额外延迟目标≤20ms；多晚8小时待机对照额外耗电目标≤1个百分点，不允许新增定时唤醒。

KUAL 的 `Export sanitized status` 会额外生成 `service-probe.json`，一次性读取本项目 Upstart 服务及全部后代的 PID、启动 tick、CPU tick 和 RSS，不读取进程参数，不新增采样定时器。它只是当前快照，不能证明峰值或续航达标。测 CPU 时，在自然运行前后分别导出并另存两份快照；仅当服务树 PID/启动 tick 未变、`rss_complete=true`、`truncated=false` 且 tick 频率可用时，才能按 `ΣCPU tick差 / tick频率 / uptime秒差 × 100%` 估算该区间单核平均占用。进程重启或中途新建/退出 worker 会使该比较不完整，应另行记录，不能填写通过。

## 3. 新阅读的受控试传

禁止取旧试传待核验记录重试。为同一微信读书账号建立新的设备身份并完成交接；旧 Mac 仍保留账本和只读复核。使用安装后**新增、完整、来源与时区均可核验**的短阅读会话，建议先正常读30–45秒并翻几页，返回首页等待空闲。不能将较长会话剪成虚构短样本。

先准备不可变试传计划：

```sh
ksync-worker --root /var/local/kindle-native-sync sync --trial --prepare --book-id LOCAL_BOOK_KEY --max-seconds 60
```

核对返回的书籍、日期、真实秒数和plan_id后，再显式提交同一计划：

```sh
ksync-worker --root /var/local/kindle-native-sync sync --trial --confirm --plan-id PLAN_ID
```

试传仍需真实设备验收；它仅允许协议验收尚未完成这一项例外，自动同步必须两项均通过。每次只能发一笔，HTTP成功或succ=1均不能单独视为到账。需同时核对单书累计增量、目标日期增量与原有位置。收到明确成功回执但统计未匹配时，保留待核验账本，可用 `reconcile --plan-id PLAN_ID` 只读复核，不发原POST。请求结果未知或仍处于发送状态时，继续封锁该计划，不能用此命令认定成功或重传。

真实验证矩阵：单次关书、同书同小时的后续会话、同书多小时、跨午夜、隔天联网补传、手机同时阅读、认证续期，以及在发送边界断网/进程退出。每项保存脱敏的前后统计和来源ID；不能把一次13秒或75秒成功外推为矩阵已全部通过。

## 4. 开启与维护

验收文件格式及绑定由worker说明定义；占位模板的布尔值必须保持false，直到相应真实测试完成。配置/书籍映射发生变化会使旧绑定失效，应重新核对再启用，不能直接复制别人的通过文件。

至少连续一周独立使用后再宣称稳定支持。升级、卸载、存储不足和网络故障都应保留未确认账本。已确认事件可安全压缩清理；任何未确认、未匹配、来源变化或覆盖缺口均不得被自动删掉。
